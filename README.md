# java-lotto-precourse

## 구현 기능 목록

### 입출력 기능 
- 구입 금액, 당첨 번호, 보너스 번호 입력 기능
- 구매한 로또 수량, 번호, 당첨 통계 및 수익률 출력 기능
- camp.nextstep.edu.missionutils.Console API를 활용하여 입력을 처리한다.
- 예외 발생 시 "[ERROR]"로 시작하는 문구를 출력한다.

### Lotto
- 로또 한 장은 1~45 사이의 중복되지 않은 6개의 숫자로 구성된다.
- 생성 시 다음 유효성 검사를 수행한다. (번호 개수가 6개인지 확인, 중복된 번호가 없는지 확인, 1~45 범위를 벗어나지 않았는지 확인)
- 유효하지 않은 입력일 경우 IllegalArgumentException을 발생시킨다.
- `[ERROR]`로 시작하는 에러 메시지를 출력한다.
- 로또 번호는 **항상 오름차순으로 정렬**되어 저장된다.

### 로또 자동 발행 기능
- 구입 금액을 입력받아 해당 금액만큼 로또를 자동 발행한다.
- 로또 1장의 가격은 1,000원이며, 구입 금액은 반드시 1,000원 단위여야 한다.
- 금액이 1,000원 미만이거나 1,000원 단위가 아닐 경우 예외를 발생시킨다.

### 당첨 번호 및 보너스 번호 관리
- 사용자가 입력한 당첨 번호(6개) 와 보너스 번호(1개) 를 관리한다.

### 당첨 결과 및 수익률 계산
- 사용자가 구매한 로또 목록과 당첨 번호를 비교하여 당첨 결과를 계산한다.
- 각 등수별로 당첨 횟수를 저장한다.
- 총 상금을 계산하고, 구입 금액 대비 수익률을 계산한다.
